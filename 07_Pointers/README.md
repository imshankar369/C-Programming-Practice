# 07 - Pointers

## 📌 Objective

This folder contains C programming problems based on **Pointers**. These programs help understand how pointers work, how they store memory addresses, and how they are used with variables, arrays, strings, functions, and structures.

---

## 📖 Topics Covered

- Introduction to Pointers
- Pointer Declaration & Initialization
- Pointer Arithmetic
- Pointers with Variables
- Pointers with Arrays
- Pointers with Strings
- Passing Pointers to Functions
- Swapping Values Using Pointers
- Double Pointers
- Pointers and Structures
- Dynamic Memory Allocation (Basic)
